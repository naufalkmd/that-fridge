# ThatFridge — mobile (Expo / React Native)

iOS-first native app. See `../../TO_DO.md` for the plan, scope, and role split.

## Run

```bash
pnpm install            # from the repo root
cp .env.example .env    # then edit EXPO_PUBLIC_API_URL
pnpm start              # or: pnpm ios
```

On a physical device, set `EXPO_PUBLIC_API_URL` to your machine's LAN IP (e.g.
`http://192.168.1.20:8000/api`), not `127.0.0.1`.

## Stack

- **Expo SDK 57** + **Expo Router** (file-based routing, `src/app/`)
- **NativeWind** for styling — Tailwind classes, config in `tailwind.config.js`
  (palette mirrors `apps/web` `lib/thatfridge/theme.ts` by hand for now)
- **@thatfridge/core** (`packages/core`) — shared types + HTTP client
- `expo-secure-store` (auth token), `expo-camera` (barcode scan),
  `expo-notifications` (local expiry reminders), `expo-haptics`

## Layout

```
src/
├── app/            expo-router screens only
│   ├── _layout.tsx root stack
│   └── index.tsx   scaffold home / API connectivity check
└── lib/
    └── api.ts      HTTP client wired to expo-secure-store + EXPO_PUBLIC_API_URL
```

## Builds

`eas.json` has `development` / `preview` / `production` profiles. Run `eas init` once
to attach the EAS project id, then `eas build --profile development --platform ios`.
Update the `EXPO_PUBLIC_API_URL` in `eas.json` once the production API domain is set.

## Native config

Managed workflow — `ios/` and `android/` are generated by `expo prebuild` and are
gitignored. Bundle id `test.thatfridge.app`. Camera usage string and export-compliance
flag are set in `app.config.ts`.
