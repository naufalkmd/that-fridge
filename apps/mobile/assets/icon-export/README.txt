ThatFridge - App Icons Export
==============================

Every icon actually used in the ThatFridge mobile app, extracted from the two
icon fonts the app bundles (Ionicons + MaterialCommunityIcons, via
@expo/vector-icons). Each icon is a transparent PNG at 512x512px.

Folders:
  white/ionicons/...                 - white icon, transparent background
  white/materialcommunityicons/...
  black/ionicons/...                 - black icon, transparent background
  black/materialcommunityicons/...

Filenames match the icon's original library name (e.g. home-outline.png,
chef-hat.png). Recolor freely in your editor - these are single-color shapes.

Counts: 57 Ionicons, 78 MaterialCommunityIcons (135 total, x2 colors = 270 files).
