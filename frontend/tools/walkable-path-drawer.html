Walkable path drawer

How to use this:
  1. Tap a crew member's tab below (Chef / Organizer / Guardian / Shop) to select them.
  2. Tap points on the art tracing a line through where they should be allowed to walk. 2 points minimum, add as many as you like for a longer or bent path.
  3. They'll immediately start wandering back and forth along that line, live - same speed and randomness as the real app.
  4. Made a mistake? "Undo point" removes the last one, "Clear path" starts that crew over.
  5. Switch tabs and repeat for each crew member.
  6. When they all look right, press "Export paths", then "Copy", and paste the result back to me in chat.

Each point is leftPct/topPct - % of the container, matching CrewScene.tsx's ZONES exactly. The live sprites here use the identical wander algorithm the app uses (see useWalker in CrewScene.tsx), so what you see is what ships.
